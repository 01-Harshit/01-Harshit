## 🚀 Featured Projects

### 📊 [Graph Generator](https://github.com/01-Harshit/graph-generator)
AI-powered chart generator that turns a question into an interactive ECharts visualization — from business data to math function plots and Linear Programming problems with feasible regions and optimal points.
- **Stack:** Python, FastAPI, React, PostgreSQL (Supabase), Redis (Upstash), SQLAlchemy, Groq API, SciPy
- Multi-model LLM fallback chain with retry, Redis caching and per-IP rate limiting

Dual-portal platform where teachers manage projects/tasks and students form groups via invite codes and peer evaluations.
- **Stack:** Python, Django, Django REST Framework, SQLite, JavaScript, Postman
